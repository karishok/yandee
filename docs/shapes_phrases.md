# Игра «Фигурки» — фразы для записи

<!-- Этот файл создан командой `dart run tool/write_shapes_phrases_doc.dart`. Не правь его руками — правки пропадут при следующем запуске. -->

Всего **27 фраз** в **3 частях**. Одна часть — одна запись в Logic и одна команда. Записывают так же, как фразы «Монстриков» (`docs/monsters_phrases.md`): фразы подряд сверху вниз, между ними молчать около 2 секунд, Bounce в WAV, файл — в папку `tool`, затем команда части.

Длинные реплики игра собирает из целых фраз: «Новая фигурка!» + «Звезда!», «Домик!» + «Ура!». Поэтому каждое слово записывается один раз.

## Советы по интонации

- Названия форм — радостно и ясно, как будто показываешь игрушку: запись звучит и сама по себе, и после «Новая фигурка!».
- Названия картинок — с удивлением и восторгом: «смотри, что получилось!»; после них игра скажет «Ура!».
- «Не сюда!» — мягко, без упрёка: это подсказка, а не ошибка.
