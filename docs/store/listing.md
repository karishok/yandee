# Yandee — тексты для страниц в сторах

Готовые тексты для App Store Connect и RuStore Консоли. Лимиты знаков
указаны в скобках, рядом — фактическая длина.

Описание упоминает режим «Фонарик», которого нет в версии 1.1.0. Эти
тексты выкладываются вместе с версией 1.2.0 — в ней фонарик есть.

Скриншоты: `docs/store/screenshots/` — PNG 1206×2622 для App Store
(iPhone 6,3″, обязательный размер); `docs/store/screenshots_rustore/` — JPG 1080×1920 для
RuStore, который обрезает всё, что не 9:16.

## App Store

**Название** (30) — 27:

```
Yandee: первые слова малыша
```

**Подзаголовок** (30) — 30:

```
Развивающая игра для детей 1–3
```

**Ключевые слова** (100) — 99. Слова из названия и подзаголовка сюда не
входят: App Store и так ищет по ним.

```
малыши,обучающие,учим,говорить,речь,карточки,животные,ферма,найди,предмет,ребенок,фонарик,звери,год
```

**Промо-текст** (170) — 141. Меняется в любой момент, без новой версии.

```
Малыш нажимает на предмет и слышит его название. 10 сцен, больше 100 слов, живой голос. Без рекламы, без регистрации, работает без интернета.
```

**Категории:** основная — «Образование», дополнительная — «Игры».
Возрастная группа «Для детей: 5 лет и младше» остаётся.

**Описание** (4000):

```
Yandee — спокойная игра, в которой малыш 1–3 лет узнаёт первые слова. Ребёнок нажимает на предмет на картинке и слышит, как он называется. Без спешки, очков и таймеров — в своём темпе.

ТРИ СПОСОБА ИГРАТЬ

• Исследовать. Нажал на предмет — услышал название. Можно просто вести пальцем по картинке: игра назовёт всё, чего коснётся малыш.

• Найти. «Где светофор?» — игра называет предмет и просит его показать. Получилось — звучит радостный сигнал. Ошибся — мягкая подсказка, без слова «неправильно».

• Фонарик. Картинка прячется в темноте. Малыш водит лучом, находит тех, кто спрятался, и собирает звёздочки.

10 СЦЕН ИЗ ЖИЗНИ МАЛЫША

Дом, кухня, ванная, улица, площадка, игрушки, ферма, зоопарк, лес и море. Больше 100 слов: животные, транспорт, посуда, игрушки и всё, что ребёнок видит каждый день.

В сценах «Лес» и «Зоопарк» рисунок можно переключить на картинку «как в жизни» — чтобы малыш узнавал зверей не только нарисованными.

РОДИТЕЛЯМ

• Бесплатно, без рекламы, встроенных покупок и подписок.
• Без регистрации: игра не спрашивает ни имени, ни почты.
• Не собирает данные: нет аккаунтов, аналитики и трекеров.
• Работает без интернета — в дороге, в очереди, на даче.
• Каждое слово произносит живой голос.
• В настройках есть подсказка, как закрепить игру на экране, чтобы малыш случайно из неё не вышел.

Играйте вместе: повторяйте слова за игрой, спрашивайте «а где собачка?» и радуйтесь каждой находке.
```

**Что нового** — для версии с фонариком:

```
• Новый режим «Фонарик»: картинка прячется в темноте, малыш водит лучом и находит тех, кто спрятался. Работает во всех десяти сценах.
• Названия предметов теперь звучат до конца, даже если малыш быстро нажимает на всё подряд.
```

## RuStore

**Название** (50) — 27:

```
Yandee: первые слова малыша
```

**Краткое описание** (80) — 73:

```
Малыш нажимает на предмет и слышит название. Без рекламы и без интернета.
```

**Полное описание** — тот же текст, что для App Store.

**Что нового** — RuStore переходит с 0.1.0 сразу на актуальную версию:

```
• Пять новых сцен: «Площадка», «Зоопарк», «Лес», «Игрушки» и «Море». Всего десять сцен и больше 100 слов.
• Новый режим «Фонарик»: картинка прячется в темноте, малыш водит лучом и находит тех, кто спрятался.
• В сценах «Лес» и «Зоопарк» рисунок можно переключить на картинку «как в жизни».
• Названия предметов звучат до конца, даже если малыш быстро нажимает на всё подряд.
```

**Категория:** «Детские» — уже стоит, не менять.
