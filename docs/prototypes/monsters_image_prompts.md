# «Монстрики» — промпты для картинок

Стиль берём со сцен «Лес» и «Игрушки» (`assets/demo_content/forest/background.png`,
`assets/demo_content/toys/background.png`): книжная иллюстрация, гуашь и цветные
карандаши, видна бумага, мягкий тёплый коричневый контур.

## Как генерировать

1. Открой **новый чат** в ChatGPT. Прикрепи картинку сцены «Лес» или «Игрушки» и
   отправь сообщение из раздела «Начало чата».
2. Дальше в **этом же чате** отправляй короткие сообщения по одному, из списков ниже.
   Так все картинки получатся в одном стиле.
3. Если стиль поплыл, напиши: «Стиль как на первой картинке: гуашь, карандаш,
   мягкий коричневый контур».
4. Если фон не прозрачный, ничего страшного: пусть будет чисто белый, я уберу его сама.
5. Сохраняй файлы под именами из списков и складывай в папку `assets/monsters/`.

**Начни с пробной партии:**
- красный монстрик: 4 лица и ручка;
- 4 красные еды;
- фон;
- поднос.

Я вставлю их в прототип, и мы посмотрим, как это выглядит в игре. Только потом
делай остальное. Всего картинок около 100.

## Начало чата (отправить один раз, с прикреплённой картинкой сцены)

```
Я делаю детскую игру для малышей 1–3 лет. Нарисуй для неё серию картинок
строго в стиле приложенной иллюстрации. Это правило для всех картинок
в этом чате:

— детская книжная иллюстрация, нарисована вручную гуашью и цветными
  карандашами, видна лёгкая фактура бумаги и мазки;
— мягкий тёплый тёмно-коричневый контур (не чёрный);
— тёплый мягкий свет сверху слева, объём мягкий, без глянца;
— цвета чистые, сочные и тёплые, без неона и кислотных оттенков;
— формы простые, крупные и округлые, без мелких деталей;
— всё доброе и милое, ничего страшного;
— никакого текста, букв, рамок и подписей.

Каждая картинка — один предмет или один персонаж, по центру, целиком,
на прозрачном фоне, без тени на полу, квадрат 1024×1024.

Пока ничего не рисуй, просто ответь «Понятно», дальше я буду присылать
задания по одному.
```

## Монстрики

У каждого монстрика 5 картинок: 4 лица и одна ручка.

- **Лица** — это одна и та же картинка, меняется только рот и глаза.
- **Ручка** рисуется отдельно, потому что в игре монстрик ею машет и хлопает.
  Вторую руку я сделаю зеркальной копией.

Все монстрики одной формы: круглое пушистое тело, как пухлая подушка, и две
короткие толстые ножки. Отличаются они цветом, «украшением» на голове и числом глаз.

| Цвет | Файл | Цвет тела | На голове | Глаза |
|---|---|---|---|---|
| красный | `red` | ярко-красный, тёплый | два маленьких кремовых рожка | два больших круглых |
| синий | `blue` | насыщенный синий | две усика-антенны с шариками на концах | два больших круглых |
| жёлтый | `yellow` | солнечно-жёлтый | пушистый хохолок | один большой глаз посередине |
| зелёный | `green` | свежий травяной зелёный | два круглых ушка с розовым внутри | три маленьких глаза в ряд |
| оранжевый | `orange` | апельсиново-оранжевый | пушистый хохолок | один большой глаз посередине |
| фиолетовый | `purple` | сиреневато-фиолетовый | два маленьких кремовых рожка | два больших круглых |
| розовый | `pink` | нежно-розовый, но яркий | два круглых ушка с розовым внутри | три маленьких глаза в ряд |
| коричневый | `brown` | шоколадно-коричневый | две усика-антенны с шариками на концах | два больших круглых |
| голубой | `lightblue` | небесно-голубой (светлее синего) | два маленьких кремовых рожка | два больших круглых |
| белый | `white` | молочно-белый, с мягкими серо-бежевыми тенями, чтобы был виден на светлом | пушистый хохолок | один большой глаз посередине |
| чёрный | `black` | чёрный, но мягкий, тёплый угольный, шерсть видна | два круглых ушка с розовым внутри | три маленьких глаза в ряд |

### 1. Лицо «спокойный» — `red_idle.png`

Это первая картинка монстрика, остальные делаются из неё.

```
Нарисуй монстрика для игры. Цвет тела — ярко-красный, тёплый.
Тело круглое и пушистое, как пухлая подушка, на двух коротких толстых
ножках, шерсть мягкая, с видимой фактурой. Животик чуть светлее.
На голове два маленьких кремовых рожка. Два больших круглых глаза:
белые, с тёмными зрачками и бликом, смотрят прямо на нас.
Ротик — улыбка с закрытым ртом, розовые щёчки.
РУК НЕТ СОВСЕМ — бока гладкие, руки я добавлю отдельно.
Стоит прямо, анфас, по центру, занимает почти весь кадр.
Прозрачный фон, без тени на полу.
```

Для других цветов поменяй в промпте цвет тела, «на голове» и глаза по таблице.
Чтобы монстрики были похожи друг на друга, можно писать так:

```
Такой же монстрик в том же стиле и той же позе, но синий (насыщенный
синий), вместо рожек — две усика-антенны с шариками на концах,
глаза те же — два больших круглых. Рук нет. Прозрачный фон.
```

Только рука, без тела. Прозрачный фон.

## Фон и поднос

### Фон — `background.png` (вертикальный, 1024×1536)

```
Нарисуй фон для игры, вертикальный, 1024×1536, в том же стиле.
Уютная тёплая кухня, но почти пустая и спокойная: светлая кремовая стена
с едва заметным узором, мягкий солнечный свет из окна сбоку.
Внизу, в нижней четверти, — край деревянного стола.
Середина картинки пустая и спокойная — там будут стоять монстрики,
поэтому никаких предметов, людей и животных в середине.
Цвета приглушённые и тёплые, чтобы монстрики и еда были главными.
Без текста.
```

### Поднос — `tray.png` (горизонтальный, 1536×1024)

```
Нарисуй пустой деревянный поднос с бортиками, вид спереди и чуть сверху,
горизонтальный, широкий и невысокий. Тёплое светлое дерево, мягкие края.
Внутри пусто. Прозрачный фон, без тени на полу.
```
