# Yandee — фонарик: ищем только зверей, найденный проступает по силуэту (дизайн)

Дата: 2026-11-14
Статус: утверждено пользователем, готово к планированию реализации

## 1. Проблема

Первая версия игры с фонариком (сцена «Лес», коммит `5f2b453`) на
телефоне оказалась странной по двум причинам:

1. **Находить слишком легко.** Целью считается любой предмет сцены, а 16
   зон «Леса» покрывают почти всю картинку — почти любое касание сразу
   что-то «находит», искать фонариком не приходится.
2. **Найденное — овальные пятна.** У предметов есть только прямоугольная
   зона, поэтому найденный предмет открывается размытым овалом по этой
   зоне. Одинаковые предметы (шесть кусков тропинки, два дерева)
   открываются разом, в том числе далеко от пальца.

## 2. Что входит / не входит

**Входит:**
- целями фонарика становятся только предметы, у которых в данных сцены
  есть контур (в «Лесу» — медведь, лиса, заяц, белка, ёж);
- найденный зверь проступает из темноты по своему силуэту;
- контуры пяти зверей для обеих картинок «Леса» (рисованной и
  реалистичной).

**Не входит:** размер и положение луча, поведение света при поднятом
пальце, порядок поиска, озвучка, режимы «Смотри» и «Найди».

## 3. Поведение

- В темноте прячутся только цели. Звёзд наверху — по числу целей (в
  «Лесу» пять).
- Цель засчитывается, когда палец вошёл в её зону (`rect`) — как и
  раньше. В режиме фонарика попадание проверяется **только по целям**:
  зона дерева или тропинки, лежащая поверх зоны зверя, его не заслоняет.
- Остальные предметы в режиме фонарика молчат и ни на что не влияют —
  луч их просто показывает.
- Найденная цель называет себя и остаётся видна: в темноте вырезается её
  силуэт с мягким краем, с прежней «выпрыгивающей» анимацией появления.
  Повторное касание найденной цели снова называет её.
- Подсказка-мерцание (после 6 секунд без движения света) показывает на
  ближайшую ещё не найденную **цель**.
- После последней цели включается свет — как и раньше.

## 4. Данные сцены

Контур хранится в `scene.json` многоугольником в долях картинки (0..1),
как и `rect`:

```json
{"id": "fox", "label": "Лиса", "audio": "fox.wav",
 "rect": {...},
 "outline": [[0.031, 0.512], [0.058, 0.471], ...]}
```

Для реалистичной картинки контуры лежат рядом с её зонами:

```json
"realistic": {"background": "...", "rects": {...},
              "outlines": {"fox": [[...], ...]}}
```

Правила:
- `outline` необязателен. **Цель фонарика — предмет, у которого есть
  `outline` на основной картинке.** Игра предлагается в сцене, где есть
  хотя бы одна цель; зашитый в код список `{'forest'}` убирается.
- На реалистичной картинке предмет берёт контур из `realistic.outlines`.
  Если его там нет, а зона у предмета своя (`realistic.rects`), контура
  на этой картинке нет — найденный предмет открывается прежним мягким
  овалом по зоне (запасной вариант, цель остаётся целью). Если своей
  зоны нет, предмет стоит там же и сохраняет основной контур.
- Старые версии приложения поля не читают и работают как раньше.
- Версия «Леса» поднимается с 3 до 4, чтобы обновлённая сцена
  пересеялась в кэш на устройствах.

## 5. Реализация

- `lib/domain/models/object_outline.dart` — новый `ObjectOutline`
  (список точек, `fromJson` из `[[x, y], ...]`).
- `SceneObject.outline` (необязательное); `SceneVariant.outlines`;
  `Scene.objectsFor` подставляет контур по правилам из §4.
- `FlashlightMode` считает целями только предметы с контуром
  (`isTarget`), остальные касания игнорирует.
- `SceneController.hasFlashlight` — «в сцене есть цели»; в режиме
  фонарика попадание пальца проверяется только по целям.
- `FlashlightDarkness` вырезает найденную цель по контуру (заливка плюс
  обводка для небольшого запаса вокруг силуэта, размытый край), без
  контура — овалом; подсказка смотрит только на цели.
- `tool/extract_outlines.py` — разовый скрипт: вырезает силуэт предмета
  из картинки по его зоне (GrabCut), упрощает до многоугольника и
  дописывает в `scene.json`. Нужен только при подготовке контента.

## 6. Проверка

- Модульные тесты: разбор `outline`/`outlines`, `objectsFor`,
  `FlashlightMode` (цели, игнорирование остальных, завершение раунда),
  `SceneController.hasFlashlight`.
- Виджет-тесты: число звёзд, не-цель не находится, цель под зоной
  не-цели находится.
- Тест на собранные сцены: у «Леса» пять целей, контуры есть на обеих
  картинках, точки в пределах 0..1.
- Контуры проверяются наложением на картинки и затем на телефоне.
